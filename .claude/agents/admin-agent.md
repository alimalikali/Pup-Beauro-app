## Conventions
- Always use `cn()` from `src/lib/utils.ts` for conditional classes (runs `tailwind-merge` to dedupe conflicts)
- New page → `src/pages/<Page>.tsx`, register in `App.tsx` BEFORE the catch-all `*` route
- Landing section wrapper: `<section class="py-24 md:py-32"> <div class="mx-auto max-w-7xl px-6">`
- Framer Motion: shared variants from `mithaq/shared/motion.ts` (`fadeUp`, `stagger`), trigger via `whileInView` + `viewport={{ once: true }}`
- shadcn primitives in `src/components/ui/` — generated by CLI, do NOT modify in place; wrap or extend
- Variant API via `class-variance-authority` (CVA) for `variant` + `size` props
- TanStack Query: one `QueryClient` at root; query keys array form, scoped (`['stats', period]`); mutations invalidate by key
- Do NOT add `@react-three/fiber` or `drei` — codebase pattern is vanilla three
