# Add shadcn component: $ARGUMENTS

## 1. Check if it exists first

`ls admin/src/components/ui/` — there are ~45 primitives already. Reuse before creating.

## 2. If creating a new variant of an existing primitive

Extend the existing file's CVA variants — do not modify the base. Example for adding a `size: "xl"` to `button.tsx`:
```ts
const buttonVariants = cva(
  'inline-flex items-center ...',
  {
    variants: {
      size: { sm: 'h-9 px-3', md: 'h-10 px-4', lg: 'h-11 px-8', xl: 'h-12 px-10 text-base' },
      // ...
    },
  },
);
```

## 3. If creating a wholly new primitive

Create `admin/src/components/ui/$ARGUMENTS.tsx`. Mirror the structure of `button.tsx`:

```tsx
import * as React from 'react';
import * as RadixPrimitive from '@radix-ui/react-<primitive>';
import { cva, type VariantProps } from 'class-variance-authority';
import { cn } from '@/lib/utils';

const $ARGUMENTSVariants = cva(
  'base-tailwind-classes-here',
  {
    variants: {
      variant: { default: '...', secondary: '...' },
      size: { sm: '...', md: '...', lg: '...' },
    },
    defaultVariants: { variant: 'default', size: 'md' },
  },
);

export interface $ARGUMENTSProps
  extends React.ComponentPropsWithoutRef<typeof RadixPrimitive.Root>,
    VariantProps<typeof $ARGUMENTSVariants> {}

export const $ARGUMENTS = React.forwardRef<
  React.ElementRef<typeof RadixPrimitive.Root>,
  $ARGUMENTSProps
>(({ className, variant, size, ...props }, ref) => (
  <RadixPrimitive.Root
    ref={ref}
    className={cn($ARGUMENTSVariants({ variant, size }), className)}
    {...props}
  />
));
$ARGUMENTS.displayName = '$ARGUMENTS';
```

## Rules

- **Always use `cn()`** from `@/lib/utils` for class merging (runs `tailwind-merge` to dedupe conflicts)
- **Default variants always defined** — never leave a variant ambiguous
- **Expose `className` prop** merged via `cn(base, className)` so consumers can override
- **Mithaq palette** for brand colors — `mithaq-hot`, `mithaq-rose`, etc. Never raw hex in JSX.
- **No inline magic numbers** for radius/spacing — Tailwind utility classes only
- **forwardRef + displayName** — every primitive
- **Do NOT modify shadcn primitives generated by the CLI in place** — wrap or extend instead. If you must change a generated file, leave a one-line comment noting why.

## Verify

- Import and use in a page — `cn()` should merge classes cleanly
- Try every variant — confirm visual differentiation
- Try overriding via `className` prop — confirm `tailwind-merge` resolves conflicts correctly (e.g., `<X className="bg-red-500" />` overrides `bg-mithaq-hot`)
- Run `npm run build` — no type errors
