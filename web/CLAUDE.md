# admin/ — Vite landing/admin SPA

Auto-loaded when work touches `admin/`. Vite/React/Tailwind/shadcn/Three.js specifics live here.

## Stack

Vite 5, React 18, React Router 6, TanStack Query 5, Tailwind 3.4, shadcn/ui (25+ Radix primitives), **vanilla Three.js 0.184** (NOT r3f), Framer Motion 12, React Hook Form + Zod, vitest 3. Package manager: **npm** (not pnpm — different from the other two sub-projects).

## Commands

```bash
cd admin
npm install
npm run dev                 # Vite — http://localhost:8080
npm run build
npm test                    # vitest run
npm run test:watch
```

## Entry chain

`main.tsx` → `App.tsx` (QueryClient + BrowserRouter) → `Routes` → `pages/Index.tsx` (landing) + `*` 404.

## Build / Vite config

`vite.config.ts`:
- Plugins: `@vitejs/plugin-react-swc`, `lovable-tagger` (dev mode component labeling)
- Alias: `@` → `src/`
- Dedupe: react, react-dom, @tanstack/react-query (prevents dual instances)
- Server: port 8080, IPv6
- HMR overlay disabled

`tsconfig.app.json`:
- Target ES2020, JSX `react-jsx`
- Strict mode **OFF** (`noImplicitAny: false`, `strictNullChecks: false`) — rapid-dev mode
- Path aliases `@/*` supported

Don't re-enable strict mode without discussion — a wave of new errors will surface.

## Routing

Declarative in `App.tsx` using React Router v6. Single landing page (`/`) with catch-all `*` route for 404.

**Catch-all stays last.** `*` matches anything — placing it before another route makes the latter unreachable.

## UI layer

shadcn primitives in `src/components/ui/` (~45 components). Generated by CLI — do NOT modify in place. Wrap or extend instead.

Variant API: `class-variance-authority` (CVA) for `variant` + `size` props. Default variants always defined.

Always use `cn()` from `src/lib/utils.ts` for conditional classes — runs `tailwind-merge` to dedupe conflicts.

## Three.js — disposal contract (non-negotiable)

Vanilla three only. Do NOT add `@react-three/fiber` or `drei`.

Every `useEffect` creating a scene MUST return a cleanup that does ALL of:
1. `cancelAnimationFrame(rafId)`
2. Remove every `window` event listener attached
3. `renderer.dispose()`
4. Traverse the scene, dispose every geometry + material (array or single)
5. `mount.removeChild(renderer.domElement)`

Skip any one → leaked GPU memory on hot reload / route change.

DPR cap: `Math.min(window.devicePixelRatio, 2)`.

Mobile gate: `hidden md:block` on the wrapper unless mobile WebGL is required.

## Motion

Framer Motion variants in `src/components/mithaq/shared/motion.ts`. Reuse `fadeUp`, `stagger`.

Trigger on scroll: `whileInView` + `viewport={{ once: true }}`. Animations should NOT re-trigger on every scroll-by.

## TanStack Query

Single `QueryClient` at root (in `App.tsx`). Never construct per page/hook.

Query keys: array form, scoped (`['stats', period]`). Mutations invalidate by key.

No global `staleTime` override — default works for static landing data.

## Testing

Vitest with jsdom + globals (no `describe`/`it` imports). Files: `src/**/*.{test,spec}.{ts,tsx}`. Setup: `src/test/setup.ts`.

Only a placeholder test exists today. New components should at minimum get a smoke test (renders without throwing).

## Common pitfalls

- Forgetting to dispose Three.js materials/geometries → memory leak
- Forgetting `-webkit-` backdrop-filter prefix → no blur on Safari
- Using `overflow-hidden` on parents with positioned pseudo-elements (mesh orbs need overflow)
- Adding listeners to `window` without cleanup → handler stacks on hot reload
- Modifying generated shadcn primitives in place instead of wrapping
