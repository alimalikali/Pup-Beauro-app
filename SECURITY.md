# Security policy

Mithaq handles sensitive identity and relationship information. Please do not report vulnerabilities in public issues.

## Reporting a vulnerability

Email the maintainers at **security@example.com** with the affected version, impact, reproducible steps, and suggested remediation if known.

Replace the placeholder address above with a monitored project security mailbox before publicly announcing the repository. Maintainers should acknowledge reports within three business days and provide status updates until resolution.

## Supported versions

Until the first stable release, only the latest commit on the default branch receives security fixes.

## Sensitive data

Never send real passwords, access tokens, identity documents, private messages, or production database contents. Use synthetic data and redact screenshots and logs.
